# Bot_Discord
Bot insano do discord pra encher linguiça

## Bom Dia - Task Principal
Uma vez ao dia, manda uma mensagem de **Bom Dia** com o **horário atual**.
- Com o objetivo de enviar a mensagem exatamente as **6h30 AM**.
- Retorna uma mensagem especial ao enviar no horário desejado.
- Toda vez que erra o horario, este é excluido da lista, aumentando as chances de acerto.
- Tem um contador de **Dias**, **Chance de Acerto** e **Defasagem** em relação as 6h30.

![Imagem da Task](/DOC/Bom_dia_ex.png "Bom Dia em Execução")
